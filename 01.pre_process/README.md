## Pre-processing
This directory contains notebooks to QC Droplet Paired-Tag data and reproduce QC figures in our manuscript.

- `00.MiniAtlas_barcode_filtering_demo.ipynb`: select valid barcodes by DNA FRiP and fragment number, and RNA UMI counts; includes pre-indexed samples
- `01.library_QC_summary.ipynb`: QC figures (same notebook as `02.analysis/00.qc/01.library_QC_summary.ipynb`)
